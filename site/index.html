Government Statistical Service RAP examples

UK Statistics RAP

Practical examples of reproducible analytical pipelines using public ONS data, offline assurance checks, live-source integration checks, and publishable statistical outputs.

For Analysts Building Reproducible Statistics

This site brings together compact examples that show how official statistics can move from source data to documented public outputs through repeatable code. The examples are designed for GSS analysts, reviewers, and teams improving statistical production workflows.

Labour market

Labour Market Resilience

Python dashboard covering employment, unemployment, inactivity, vacancies, and pay growth with validation checks and run metadata.

Retail sales

Retail Sales Index

Quarto statistical summary with API ingestion, tested transformations, output validation, run metadata, and trend charting.

Housing

Housing Affordability

Multi-source Quarto monitor calculating house-price-to-earnings ratios across England and Wales with explicit caveats and duplicate-key checks.

Inflation

UK Inflation Monitor

Compact time-series monitor using an ONS CPIH series with previous-period change, source metadata, and offline validation.

GDP

UK GDP Release Summary

Release-summary example calculating previous-period GDP growth from an ONS index series with revisions caveats.

Population

UK Population Change Explorer

Population-change example with area-period keys, positive-count checks, and derived change rates for demographic outputs.

Bus stops

Bus Stop Standard Data Monitor

Open-data prototype using NaPTAN to show what can currently be monitored nationally for a proposed bus stop standard, and where facility-data gaps remain.
